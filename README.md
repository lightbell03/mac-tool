# WheelSpace

마우스와 키보드로 맥을 더 빠르게 다루는 메뉴 막대 앱입니다.

- **데스크탑 전환**: Option을 누른 채 마우스 휠을 굴려 옆 데스크탑으로 이동
- **한영 변환**: 한영 전환을 놓쳐 잘못 친 글자(`dkssud` → `안녕`)를 단축키 한 번으로 바로잡기
- **창 포커스 이동**: 키보드로 왼쪽·오른쪽·위·아래 창으로 이동, 창 목록 고르기, 겹친 창 넘기기, 창을 다른 모니터·옆 데스크탑으로 보내기
- **키보드 포인터**: 키보드로 마우스 포인터를 움직이고 클릭·드래그·스크롤 (왼손만으로 쓰는 모드 포함)
- **실행 중인 앱 선택**: 숨기거나 창을 닫은 앱도 키보드로 골라 다시 보이기

계정·서버·네트워크 연결이 없고, 설정은 이 맥에만 저장됩니다. 입력한 글자나 창 제목은 기록하지 않습니다.

> 키 기호: ⌘ Command · ⌥ Option · ⌃ Control · ⇧ Shift · ⇥ Tab · ↩ Return · ←→↑↓ 방향키

---

## 설치

**필요한 것**: macOS 13 이상, Xcode Command Line Tools(`xcode-select --install`)

```sh
git clone https://github.com/lightbell03/mac-tool.git WheelSpace
cd WheelSpace
scripts/build-app.sh --install      # ~/Applications/WheelSpace.app 에 설치
open ~/Applications/WheelSpace.app
```

다시 빌드해서 설치해도 권한은 그대로 유지됩니다(이 맥 전용 서명 인증서를 처음 한 번 만들어 씁니다).

## 처음 실행과 권한

1. 실행하면 메뉴 막대에 아이콘이 생기고, 권한이 없으면 설정 창이 열립니다.
2. **권한 요청**을 누르고 시스템 설정 → 개인정보 보호 및 보안에서 WheelSpace를 허용합니다.
   - **입력 모니터링**: 휠·단축키 감지
   - **손쉬운 사용**: 키 입력 보내기, 창 이동, 포인터 조작
3. WheelSpace로 돌아오면 자동으로 다시 확인합니다. 반영되지 않으면 설정의 **앱 다시 실행**을 누릅니다.

> 항상 `~/Applications/WheelSpace.app`에서 실행하세요. 권한은 설치된 위치의 앱에 주어집니다.

## 데스크탑 전환

| 입력 | 동작 |
| --- | --- |
| Option + 휠 위 / 아래 | 왼쪽 / 오른쪽 데스크탑 |
| Option + 휠 왼쪽 / 오른쪽 | 왼쪽 / 오른쪽 데스크탑 (설정에서 켬) |
| 마우스 뒤로·앞으로 버튼 | 왼쪽 / 오른쪽 데스크탑 (설정에서 켬) |

- Option 없이 굴리면 평소처럼 스크롤됩니다.
- 시스템 설정 → 키보드 → 키보드 단축키 → Mission Control에서 "왼쪽 공간으로 이동(⌃←)"·"오른쪽 공간으로 이동(⌃→)"이 켜져 있어야 합니다.
- 설정에서 보조키(Option 대신 Control·Command·Shift), 휠 방향 반전, 전환 간격, 휠 감도를 바꿀 수 있습니다.

## 한영 변환

한영 전환을 깜빡해 잘못 입력한 글자를 바로잡습니다. 번역이 아니라 키보드 자판 위치만 바꿉니다.

1. 잘못 입력한 부분을 **선택**합니다.
2. 단축키를 누릅니다.
   - **⌃⌥K** (Control + Option + K): 영문 → 한글 (`dkssudgktpdy` → `안녕하세요`)
   - **⌃⌥E** (Control + Option + E): 한글 → 영문 (`ㅗ디ㅣㅐ` → `hello`)
3. 선택한 글자가 바로 바뀝니다. 되돌리려면 그 앱에서 ⌘Z를 누릅니다.

- 복사해 두었던 클립보드 내용은 그대로 남습니다.
- **터미널**에서는 바꾼 결과가 클립보드에만 들어갑니다. ⌃U로 입력 줄을 지우고 ⌘V로 붙여 넣으세요.
- "복사한 내용만 변환" 방식을 고르면, 직접 ⌘C → 단축키 → ⌘V 순서로 씁니다.
- "변환 후 입력 언어 맞추기"를 켜면 변환한 언어의 입력기로 자동으로 바꿉니다.
- 메뉴의 **직전 클립보드 복구**로 변환 전 클립보드를 되살릴 수 있습니다(5분 이내).

## 창 포커스 이동

여러 모니터에 놓인 창 사이를 키보드로 옮겨 다닙니다. 같은 앱의 다른 창도 각각 이동합니다.

| 단축키 | 동작 |
| --- | --- |
| ⌃⌥← / ⌃⌥→ / ⌃⌥↑ / ⌃⌥↓ | 지금 창의 왼쪽 / 오른쪽 / 위 / 아래 창으로 |

- 실제 화면 위치를 기준으로 가장 가까운 창을 고릅니다. 최소화·숨김·완전히 가려진 창은 건너뜁니다.
- **마우스 포인터 따라가기**(설정)를 켜면, 다른 모니터의 창으로 넘어갈 때 포인터도 그 창으로 옮깁니다.

### 창 목록 전환기

⌘Tab처럼 고르되, 앱이 아니라 **지금 모니터의 창**을 고릅니다. 가려진 창을 앞으로 가져올 때 편합니다.

| 입력 | 동작 |
| --- | --- |
| Option을 누른 채 ` | 창 목록이 뜨고 바로 뒤 창이 선택됨 |
| (Option을 누른 채) ` / ⇧` / 방향키 | 다음 / 이전 창 |
| Option을 떼거나 ↩ | 선택한 창을 앞으로 |
| Esc | 취소 |

### 겹친 창 넘기기

| 단축키 | 동작 |
| --- | --- |
| ⌃⌥] | 지금 창 밑에 깔린 창을 앞으로 |
| ⌃⌥[ | 직전 창으로 되돌아가기 |

이어서 누르면 지금 모니터의 창을 차례로 한 장씩 넘깁니다.

### 창을 다른 모니터로 보내기

| 단축키 | 동작 |
| --- | --- |
| ⌃⌥⌘← / ⌃⌥⌘→ / ⌃⌥⌘↑ / ⌃⌥⌘↓ | 지금 창을 왼쪽 / 오른쪽 / 위 / 아래 모니터로 |

- 보통 창은 **크기 그대로**, 원래 모니터에서와 같은 비율의 자리로 옮깁니다.
- 화면 가장자리에 붙여 둔 창(왼쪽 절반, 꽉 채움 등)은 새 모니터에서도 **같은 배치**가 되도록 크기를 맞춥니다. 왼쪽 절반에 있던 창은 새 모니터의 왼쪽 절반으로 갑니다.
- 새 모니터보다 큰 창은 화면 안에 들어가게 줄입니다.
- 전체 화면 창은 옮길 수 없고, 크기를 바꿀 수 없는 창은 위치만 옮깁니다.
- "마우스 포인터 따라가기"를 켜 두면 포인터도 옮긴 창으로 갑니다.

### 새 데스크탑 만들기·창을 옆 데스크탑으로 보내기

| 단축키 | 동작 |
| --- | --- |
| ⌃⌥⌘] (Control + Option + Command + ]) | 지금 창이 있는 모니터에 **새 데스크탑 만들기** (맨 끝에 생기고, 화면은 그대로) |
| ⌃⌥⇧[ / ⌃⌥⇧] (Control + Option + Shift + [ 또는 ]) | 지금 창을 **들고** 같은 모니터의 왼쪽 / 오른쪽 데스크탑으로 |
| ⌃← / ⌃→ (macOS 기본) | 화면만 왼쪽 / 오른쪽 데스크탑으로 |

- 창을 들고 갈 때 오른쪽에 데스크탑이 없으면 **새로 만들어서** 보냅니다(설정에서 끌 수 있음, 기본 켬). 새 데스크탑은 맨 끝에만 만들 수 있어서, 맨 왼쪽에서 왼쪽으로는 보낼 수 없습니다.
- 창을 들고 가기는 macOS가 공개하지 않은 기능을 씁니다. macOS 업데이트 뒤 동작하지 않으면 "이 macOS에서는 창을 데스크탑으로 옮길 수 없어요"라고 알려 줍니다.
- 새 데스크탑을 만들 때는 Mission Control이 잠깐 열립니다.
- 시스템 설정 → 키보드 → 키보드 단축키 → Mission Control의 "왼쪽/오른쪽 공간으로 이동(⌃← / ⌃→)"이 켜져 있어야 합니다.

## 키보드 포인터

키보드만으로 마우스 포인터를 움직이고 클릭·드래그·스크롤합니다. **기본은 꺼져 있습니다** — 설정 → 키보드 포인터에서 켭니다.

### 누른 채 쓰기

Option + Tab을 누르고 있는 동안만 포인터를 조작합니다. 손을 떼면 키보드는 평소대로 동작합니다.

| 입력 (Option + Tab을 누른 채) | 동작 |
| --- | --- |
| ←→↑↓ | 포인터 이동 (두 키를 같이 누르면 대각선) |
| ⇧ + 방향키 | 빠르게 |
| A + 방향키 | 느리게 (세밀하게 맞출 때) |
| ⌘ + 방향키 | 스크롤 |
| ↩ | 왼쪽 클릭 (두 번 = 더블클릭) |
| R | 오른쪽 클릭 |
| D | 더블클릭 |
| G를 누르고 있기 | 드래그 (떼면 놓기) |
| Esc | 드래그 취소 |

- 방향키를 짧게 톡톡 누르면 천천히 조금씩, 길게 누르면 점점 빨라집니다.
- 모든 키는 설정 → 키보드 포인터 → **단축키 설정**에서 바꿀 수 있습니다. 바꾼 뒤 **적용**을 누르세요.

### 포인터 모드 (계속 켜 두기)

**Option을 누른 채 Tab을 두 번** 누르면 포인터 모드가 켜집니다. 켜져 있는 동안은 Option + Tab 없이 위의 키만으로 조작하고, 모든 모니터 위쪽에 "포인터 모드"가 표시됩니다.

- 포인터 모드에서는 글자·숫자·Space·Tab이 **입력되지 않습니다**. 실수로 글자가 들어가지 않게 하기 위해서입니다.
- **나가기**: **I**를 누르거나, Option + Tab을 다시 두 번 누릅니다.
- **자동으로 꺼지는 경우**:
  - 글자 입력란을 클릭했을 때
  - ⌘Space(Spotlight)·⌥Space 같은 해제 단축키를 눌렀을 때
  - 메뉴나 설정 창을 열었을 때
- Esc, Fn, 기능 키(F1~), Home·End·Page Up·Page Down은 앱에 그대로 갑니다.

**포인터 모드에서 앱 단축키 쓰기**

포인터 모드 중에도 ⌘·⌃ 단축키(예: IntelliJ의 ⌘B)는 앱에 그대로 갑니다.

- **⌘를 누르고 있는 동안**은 포인터 모드가 잠깐 풀리고, ⌘를 떼면 다시 돌아옵니다.
- ⌘를 쥔 채 방향키·↩·Esc를 누르면 ⌘ 없이 전달됩니다. 그래서 ⌘B로 연 목록을 **⌘를 떼지 않고 ↓↓↩로 고를 수** 있습니다.
- ⌘를 쥔 채 **⇧만 한 번 눌렀다 떼면** 포인터 모드가 완전히 꺼집니다. 목록이나 입력창을 평소 키보드로 쓸 때 씁니다.
- 돌아올 때 단축키로 글자 커서가 옮겨 갔으면(⌘B로 다른 위치로 이동 등) 포인터가 커서 옆으로 옮겨 갑니다. 앱이 커서 위치를 알려 주지 않으면(터미널 등) 옮기지 않습니다. ⌘S처럼 포커스가 그대로면 포인터는 그 자리에 있습니다.
- ⌘C·⌘V·⌘X·⌘Z·⌘A·⌘Tab은 포인터 모드를 그대로 둡니다.

### 왼손 모드

오른손은 마우스에 둔 채 **왼손만으로** 쓰는 포인터 모드입니다. 한 손으로 방향과 동작을 함께 다루도록 단순하게 만들었습니다.

```
 Q   W   E   R   T        W A S D : 이동
   A   S   D   F          E R T / F : 스크롤 십자 (R 위 · F 아래 · E 왼쪽 · T 오른쪽)
     Z   C   V   B        Space   : 클릭
       [  Space  ]        C · V   : 오른쪽 클릭 · 드래그
```

| 키 | 동작 |
| --- | --- |
| **Option + Shift + Tab 두 번** | 왼손 모드 켜기·끄기 |
| **Q** | 포인터 모드 중 일반 ↔ 왼손 모드 바꾸기 |
| W A S D | 위·왼쪽·아래·오른쪽 이동 (같이 누르면 대각선) |
| R / F | 위 / 아래로 스크롤 |
| E / T | 왼쪽 / 오른쪽으로 스크롤 |
| ⇧ (누른 채) | 빠르게 |
| Space | 왼쪽 클릭 (두 번 = 더블클릭) |
| C | 오른쪽 클릭 |
| V | 드래그 시작 → 다시 누르면 놓기 (Esc도 놓기) |

- 누른 채 써야 하는 키는 ⇧(빠르게) 하나뿐입니다. 드래그는 V로 켜 두고 손을 뗀 채 WASD로 끌고 갈 수 있습니다.
- 드래그 중에는 화면 위 표시가 "드래그 중 · V로 놓기"로 바뀝니다.
- 방향키와 ↩도 그대로 쓸 수 있습니다.
- 왼손 모드에서 ⌘B처럼 앱 단축키를 쓴 뒤 **⌘를 쥔 채 W A S D를 누르면 방향키, Space를 누르면 ↩**로 전달됩니다. 손을 옮기지 않고 목록을 고를 수 있습니다.

### 원치 않게 포인터 모드가 풀릴 때

입력란 클릭으로 포인터 모드가 꺼지는 게 불편한 곳이 있으면:

- **그 앱 전체**: 설정 → 키보드 포인터 → **해제하지 않을 앱**에 추가합니다(예: IntelliJ).
- **그 영역만**: 풀린 직후 메뉴 막대의 **방금 해제 취소하고 이 영역 제외**를 누릅니다. 웹 페이지라면 **모든 브라우저에서 제외**도 고를 수 있습니다.

## 실행 중인 앱 선택

| 입력 | 동작 |
| --- | --- |
| ⌃⌥⇥ (Control + Option + Tab) | 실행 중인 앱 목록 열기 (최근 사용 순) |
| 글자 입력 / ↑↓ | 이름으로 찾기 / 고르기 |
| ↩ | 그 앱의 창 보이기 |
| Esc | 취소 |

숨긴 앱(⌘H), 최소화된 창만 있는 앱, ⌘W로 창을 모두 닫은 앱도 창을 다시 보여 줍니다. 창이 없으면 Dock 아이콘을 누른 것처럼 다시 엽니다.

Docker처럼 창을 닫으면 메뉴 막대로 숨는 앱은 설정의 **목록에 함께 보일 앱**에 넣으면 목록에 나옵니다.

## 메뉴와 설정

- **메뉴 막대 아이콘**: 기능별 켜기·끄기, 한영 변환 실행, 직전 클립보드 복구, 설정 열기, 종료
- **설정 창**: 왼쪽 목록에서 기능을 고릅니다 — 데스크탑 전환 · 한영 변환 · 창 포커스 이동 · 키보드 포인터 · 실행 중인 앱 · 일반(로그인 시 실행, 초기화, 진단 정보 복사)
- 단축키는 기능마다 설정에서 바꾸거나 끌 수 있습니다. 다른 단축키와 겹치면 경고가 표시됩니다.

## 문제가 생겼을 때

- **동작하지 않음**: 메뉴 막대 아이콘이 🔒이면 권한이 없는 상태입니다. 설정에서 권한을 다시 허용하세요.
- **권한을 허용했는데도 "필요"로 나옴**: 시스템 설정의 입력 모니터링·손쉬운 사용 목록에서 WheelSpace를 `−`로 지운 뒤 앱을 다시 실행해 허용합니다.
  ```sh
  tccutil reset ListenEvent com.bell.WheelSpace; tccutil reset Accessibility com.bell.WheelSpace
  ```
- **원인을 알고 싶을 때**: 설정 → 일반 → **상태 진단 정보 복사**를 누르면 최근 동작 기록이 복사됩니다. 입력한 글자·창 제목·페이지 내용은 들어가지 않습니다.

## 삭제

1. 설정 → 일반에서 로그인 시 실행을 끄고 WheelSpace를 종료합니다.
2. `~/Applications/WheelSpace.app`을 삭제합니다.
3. (선택) 설정 삭제: `defaults delete com.bell.WheelSpace`
4. (선택) 권한 목록 정리: 위의 `tccutil reset` 명령
